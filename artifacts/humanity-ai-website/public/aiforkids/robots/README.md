# Robotics Lab 3D robot

`robot-expressive.glb` — "RobotExpressive" by Tomás Laulhé (Quaternius),
released under CC0 1.0 (public domain). Obtained from the three.js examples
(`https://threejs.org/examples/models/gltf/RobotExpressive/RobotExpressive.glb`),
unmodified, 463,988 bytes.

Animations: Dance, Death, Idle, Jump, No, Punch, Running, Sitting, Standing,
ThumbsUp, Walking, WalkJump, Wave, Yes. Materials: Grey, Main (the shell the
child paints), Black. Rendered by `src/aiforkids/studio/RobotStage.tsx`
with `@google/model-viewer`; Death and Punch are deliberately not offered.

Served from this site so children's pages never fetch from a third party.
